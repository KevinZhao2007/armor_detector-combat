## 遇到的问题和分析
  1. 完全不知道从哪开始下手学习，虽然大概了解需要做什么但每一步怎么做有大量空白。
    解决思路：用树状图法，先让整体思路模块化，以数字识别为例，传统视觉方案本质上分为ROI截取+透视变换+预处理+网络推理，YOLO网络则是直接将整图输入交给识别网络去做，最后再加一个NMS限制即可。将每个模块需要做什么以后分别向AI问应该怎么实现，采用一种分而治之的思想
  2. 传统视觉方案标注视频的背景噪点太多，识别精度相当低
     解决思路：向deepseek找一些优化的方向，比如倾斜角不能太大，长度比不能太大或太小，连线倾斜角不能太大以及绝对亮度限制等等，这些内容在对应位置上加上后整体噪点减少，但也出现了少识别的情况，通过不断调参数找到一个相对合理的区间
  3. 对于模型的部署方法不清楚/对于原理解算原理理解不透彻
     解决过程：主要还是与AI进行交流，在交流中逐渐理解
  4. 很难提出有价值的问题，大部分时候还是需要AI喂饭
     解决过程：本质上还是基础语法不熟练和对思路理解不清楚，一方面在B站继续听网课尽量掌握更多基础语法，另一方面要求AI尽可能详细的标注每一段代码的用途以便使理解更加清晰。
